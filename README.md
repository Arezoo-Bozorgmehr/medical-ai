# Medical AI Landing Page

A simple, free static landing page for GitHub Pages.

## Before publishing

Open `index.html` and replace:

- `YOUR_EMAIL@example.com`
- `YOUR_LINKEDIN_URL`

Optional:
- Change the name/title copy
- Add your academic title if you want
- Add an Impressum / Datenschutz page before using the site commercially in Germany

## Free publishing with GitHub Pages

1. Create a free GitHub repository, e.g. `medical-ai`.
2. Upload `index.html` and `styles.css`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/root`.
6. Save.

Your page will then be available under a free GitHub Pages URL.
